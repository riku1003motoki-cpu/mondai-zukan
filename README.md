# 問題図鑑

問題番号ごとに、問題文・正解・長いAI解説・復習状態を保存して読み返すための、スマートフォン向けWebアプリです。サーバーやアカウントは不要で、まずはブラウザ内にデータを保存します。

## できること

- 年度・月ごとに分けた5ページ（2018年6月／11月、2019年6月／11月、2021年6月）。各35問から開始
- 問題は追加・削除可能。「20-1」などの表示名も可能
- 問題文、画像URL、正解、詳しい解説、注意点、暗記ポイント、キーワードの登録・編集
- 未解説／解説済み／復習したい／間違えた の状態表示と絞り込み
- 問題番号・本文・キーワードを横断検索
- 前後の問題への移動
- JSON形式のバックアップ書き出し・読み込み

## ファイル構成

```
index.html   画面の土台
styles.css   スマホ対応の見た目
app.js       画面処理とデータ保存
README.md    この説明書
```

## ローカルでの起動方法

最も簡単なのは `index.html` をブラウザで開く方法です。ただし、開発中は簡易Webサーバーの利用がおすすめです。

1. このフォルダをターミナルで開きます。
2. Pythonが入っている場合、`python -m http.server 8000` を実行します。
3. ブラウザで `http://localhost:8000` を開きます。

## 使い方

1. 上部から年度・月のページを選び、一覧の番号をタップして **編集する** を押します。
2. 問題文、正解、詳しい解説などを入力して **保存する** を押します。
3. 状態を「復習したい」「間違えた」にすると、一覧の色と記号で分かります。
4. 検索欄や状態ボタンで目的の問題を絞り込みます。
5. ときどき **書き出す** でJSONバックアップを保存してください。別の端末では **読み込む** で復元できます。

問題20の(1)と(2)のように分けたいときは、各問題を追加して、編集画面の「問題番号・表示名」を `20-1`、`20-2` のように変更してください。数字だけでなく「練習A」などの名前も使えます。不要な問題は編集画面下の「この問題を削除」で減らせます。

詳しい解説は通常の文章をそのまま貼り付けられます。`# 見出し`、`## 小見出し`、`- 箇条書き` の形も読みやすく表示されます。

## 画像について

編集画面の「問題画像」に画像のURLを貼り付けるか、端末の画像を1枚選ぶと表示できます。同一ページに複数問題が載った教材では、ページ全体の画像を各問題に設定する運用も可能です。端末から選んだ画像はデータ内に保存されるため、高解像度の画像を大量に登録するとブラウザの保存容量を使います。画像を必要なサイズにして、JSONバックアップをこまめに取ってください。

## 保存の仕組みと注意

データはこのブラウザの `localStorage` に保存されます。そのため、再読み込みしても残りますが、ブラウザのサイトデータを消すと失われます。また、端末やブラウザ間では自動同期されません。大切な内容はJSONで書き出してください。

将来クラウドDBやAI APIを導入する場合は、`app.js` の `loadData` / `saveData` をAPI通信に置き換える設計です。通常のAIチャットから、このアプリのブラウザ保存領域へ直接データを自動送信することはできません。API連携用のサーバーまたは認証付きのクラウドDBを追加すれば、AIが生成した解説を保存する流れを実装できます。

## PC・スマホの自動同期（Supabase）

この版はSupabaseを使った自動同期に対応しています。最初にSupabaseの **SQL Editor** を開き、`supabase-setup.sql` の中身をすべて貼り付けて **Run** を一度実行してください。これは、各利用者が自分のデータだけを安全に保存できるテーブルを作る作業です。

その後、アプリ右上の **同期を設定** からメールアドレスと6文字以上のパスワードで登録します。確認メールが届いたらメール内のリンクを開き、同じメールアドレスとパスワードでPC・スマホの両方からログインしてください。以降は保存時にクラウドへ自動同期します。

## GitHubへ保存する方法

1. GitHubで新しいリポジトリを作成します。
2. このフォルダの `index.html`、`styles.css`、`app.js`、`README.md` をリポジトリへアップロードしてコミットします。
3. リポジトリの **Settings → Pages** を開きます。
4. Sourceで **Deploy from a branch**、Branchで `main` と `/ (root)` を選び保存します。
5. 表示されたURLをスマートフォンのブラウザで開きます。

GitHub Pages版でもデータは各利用者のブラウザに保存されます。公開URLを共有しても、他の人のデータが見えるわけではありません。複数端末で同じデータを使うには、JSONの読み書きか、将来的なクラウド保存機能が必要です。
